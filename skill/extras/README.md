# 本地扩展：SVG 输出与逐笔绘制回放

原版 skill 的产物是 **CSS `clip-path`（div 元素堆叠）**。这个 extras 目录是本地加的两个脚本，
复用原版的算法管线（Oklab 量化 → 邻接合并 → 亚像素轮廓 → 偶奇多边形挖洞），但把输出换成
**真正的 SVG `<path>`**，并额外生成一个能回放每一笔绘制过程的 HTML。

脚本不修改原版任何文件，可单独删除。

---

## `build_svg_art.py` — 描摹成 SVG + 生成逐笔回放页

```bash
python3 <skill-dir>/extras/build_svg_art.py <参考图> \
  --out-prefix /你的输出路径/我的插画 \
  --title "画面标题"
```

产出三个文件：`<前缀>.svg`（纯矢量图）、`<前缀>.html`（逐笔回放页）、`<前缀>.json`（报告）。

### 相比原版 CLI 的额外能力

1. **真正的 SVG**：每个形状一条 `<path>`，多子路径靠 `fill-rule:evenodd` 挖洞。
2. **底板固定纸白**（`#f0f0f0`）：整幅画都在白纸上逐笔画成，起笔是一张纸、画满才成图；
   不再有「与底板色差 ≤3 的量化色整簇跳过不画」的省笔（浅色图会因此多画约 1/3 的笔数）。
   `--dark-cut` 默认 0（关闭）——给正值会把与底板相近的像素整片压平，暗部会烂掉。
3. **逐笔回放 HTML**：播放/暂停、重播、拖动进度条跳到任意一笔、0.5×/1×/2×/4×
   变速、叠加原图对照。每一笔先沿轮廓描线、再落色填充。
   实现要点：`pathLength="1"` 归一化路径长度，`stroke-dasharray/dashoffset` 描线；
   用 CSS 变量 `--i`（笔序）/`--step`（间隔）/`--seek`（定位）/`--play`（播放态）
   驱动，改速度不用遍历 DOM。重播靠 `cloneNode` 重建节点，保证动画干净重启。

### 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--max-width` | 760 | 描摹宽度上限（最长边同时被限制为 2× 该值） |
| `--colors` | 96 | 量化颜色数，2–256 |
| `--passes` | 3 | 邻接合并轮数，越大碎片越少 |
| `--epsilon` | 0.32 | 轮廓简化容差（px），越小越精细、顶点越多 |
| `--min-area` | 6 | 小于此面积的形状直接丢弃 |
| `--background` | `#f0f0f0` | 底板色，固定纸白。整幅画在白纸上逐笔画成，没有「与底色相近就跳过」的省笔 |
| `--dark-cut` | 0 | 与底板色差 ≤ 此值的像素压平为底板色，0 = 关闭（默认） |
| `--base` | 0.028 | 1× 下每笔间隔（秒），调大 = 慢速细看 |
| `--dur` | 0.5 | 单笔动画时长（秒） |
| `--order` | `sketch` | 画笔顺序。`sketch` 先起稿后铺色（像人的画法）、`area` 纯大到小、`luma` 亮到暗（旧行为）。**只影响动画观感，不影响最终画面** |
| `--sketch-ratio` | 0.02 | `sketch` 模式里「起稿阶段」占的笔数比例 |
| `--no-gradients` | — | 关闭局部渐变，所有形状纯色平涂（能省一点体积） |
| `--gradient-min-area` | 24 | 面积不小于此值的形状才拟合渐变 |
| `--ghost-format` | `webp` | 对照层编码格式，`png` 无损但大 |
| `--ghost-quality` | 90 | 对照层有损质量 |
| `--ghost-scale` | 2.0 | 对照层相对描摹尺寸的倍数（高清屏用），不超过原图分辨率 |
| `--no-ghost` | — | 不内嵌原图对照层（省约 60 KB） |

> **两个容易忽略的**：
> 底板固定纸白、且**一笔不省**——没有「与底色相近就整簇跳过」的机制；
> 想换底板色（如适配历史作品）可以给 `--background`，回放页会从 SVG 里读它，两边永远同源。
> `--order sketch` 选出来的「线稿」是**细长小碎片**（全图颜色过渡处），
> 不是轮廓线 —— 想要真线稿请用 `svg2canvas.py`。

### 画的顺序

默认 `sketch`：细长碎片（起稿）优先 → 其余按面积降序 —— 先起稿、再铺大色块、最后抠细节。
另有 `area`（纯大到小）与 `luma`（亮到暗，上游原版的旧行为）可选。
**顺序只影响回放观感，不影响 SVG 的最终画面**（形状互不重叠，本质是平面的划分）。

## `svg2canvas.py` — 把 SVG 改造成 Canvas 回放页

原版产出的回放页把每个形状都塞进 DOM 并各挂一条 CSS 动画，几万笔就开始卡、十几万笔打不开。
这个脚本把同一份图形数据重新打包成**二进制**（`Int16` 坐标、`Uint32` 索引、`Float32` 渐变），
页面里只留 **1 个 `<canvas>`**，逐帧**增量**绘制。

```bash
python3 <skill-dir>/extras/svg2canvas.py <in.svg> <原图> <out.html> "标题" \
    [秒数=80] [线稿笔占比=0] [线稿时间占比=0] [线宽=2.6]
```

它还会额外做两件事：

1. **真线稿层**：从原图 `Canny` 提边缘 → **追踪成有序折线** → 按段切开，用 `stroke` 画在最前面。
   注意**不能用 `findContours` 的轮廓去 fill** —— 边缘密集处（树叶、百叶窗、木纹）会连成大块，
   填出来是一坨几何色块，不是线稿。
2. **大色块扫描线切分**：画面 75% 的面积往往集中在前 2% 的形状里，直接播会「啪」地糊一片。
   面积超阈值的形状会被光栅化后按横条切开，一条条刷上去。
   **切横条时必须让相邻条重叠一行**，否则 1px 空档会露出底色形成横向白线。

| 位置 | 参数 | 默认 | 说明 |
|---|---|---|---|
| 1 | in.svg | — | `build_svg_art.py` 的产物 |
| 2 | 原图 | — | 用于提线稿和对照层 |
| 3 | out.html | — | 输出 |
| 4 | 标题 | — | 页面顶部 |
| 5 | 秒数 | 80 | 1× 速度下播完整幅画的时间 |
| 6 | 线稿笔占比 | 0 | **必须填 0**（占位），实际笔数由脚本从 SVG 里读 |
| 7 | 线稿时间占比 | 0 | `0`＝不单独控制：线稿按「√bbox面积 ≈ 线长」计重（实测占 3~4% 时间）；填 0~1 的小数则固定起稿阶段占比 |
| 8 | 线宽 | 2.6 | 线稿线条宽度（画布原生像素） |

> 第 6 位是历史遗留的占位参数，**照抄命令时数一遍位置**，把 `epsilon` 之类填进去会导致线宽异常。

实测：18 万笔的形状，回放页 13 MB，手机上流畅播放。

## `verify_svg.py` — 还原度自检

把生成好的形状重新栅格化，跟原图逐像素比，输出 MAE（全图 / 前景 / 缩略图）
和一张三联对比图（原图 | 重绘 | 差异）。

```bash
python3 <skill-dir>/extras/verify_svg.py <参考图> --out /tmp/verify
```

**一定要看前景 MAE，别被全图 MAE 骗了。** 暗背景图有 80% 是黑，全图 MAE 会
低得漂亮（实测 0.82），但那主要是"背景本来就是黑的"的功劳。前景（人物）
MAE 才是真实水平（同例 3.22）。

参数需与 `build_svg_art.py` 保持一致，否则比的是另一份结果。

> **`quality.py` 注意**：上游已修复「缩略图窄边可能取整为 0，导致 `cv2.resize` 报错」的问题，
> 若你的副本是旧版请同步（见仓库 `ATTRIBUTION.md`）。

## 与其他形态的关系

本扩展产出的 SVG 是**独立的矢量文件**，不含脚本、图片、外链，可直接嵌入别处。
原版 CLI 的 CSS 产物则带有原版自带的审计（拒绝 `img`/`svg`/`script`/`base64`/
外链，并写入 CSP），面向"禁止图片资源"的场景。两者按需选用：

- 需要**纯 HTML + CSS**、有资源限制 → 用原版 `scripts/image_to_css.py`
- 需要**矢量文件**、或想看绘制过程 → 用本目录的 `build_svg_art.py`
