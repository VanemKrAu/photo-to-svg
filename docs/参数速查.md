# 参数速查

## 一键入口（推荐）

```bash
$PY tools/make_art.py <原图> <作品名> [标题] [秒数] [线稿时间占比] [epsilon] [线宽]
```

| 位 | 参数 | 默认 | 说明 |
|---|---|---|---|
| 1 | 原图 | — | 支持 jpg / png / webp |
| 2 | 作品名 | — | 同时作为输出目录名和文件名 |
| 3 | 标题 | `<作品名>` | 回放页顶部显示的标题 |
| 4 | 秒数 | `90` | 1× 速度下播完整幅画的时间 |
| 5 | 线稿时间占比 | `0.15` | 起稿阶段吃掉多少播出时间 |
| 6 | epsilon | `0.25` | 轮廓简化容差。**只影响顶点数，不影响形状数** |
| 7 | 线宽 | `2.6` | 线稿线条宽度（画布原生像素） |

输出目录可用环境变量重定向：`export SVG_ART_OUT=/你的/目录`

---

## epsilon 怎么选

只改顶点数，不改形状数：

| epsilon | 形状数 | 顶点数 | SSIM@1440 | Canvas 体积 |
|---|---|---|---|---|
| 0.08 | 182640 | 2951257 | 0.9434 | ~20 MB |
| 0.25 | 182640 | 1490435 | 0.9406 | ~12 MB |

- 要发给手机 → **0.25**
- 要留档的矢量原图 → **0.08**
- 结构很"硬"的图（大量直线：建筑、栏杆、门窗）→ 0.08 提升更明显

## 分步调用（要精细控制时）

### ① 描摹

```bash
$PY tools/build_svg_art.py <原图> --out-prefix <前缀> \
  --max-width <原图宽> --colors 512 --passes 0 --epsilon 0.25 --min-area 1 \
  --background <底色> --dark-cut 0 --order sketch --no-ghost --title "标题"
```

| 参数 | 推荐值 | 为什么 |
|---|---|---|
| `--max-width` | 原图宽度 | 不降采样，保真优先 |
| `--colors` | 512 | 压低渐变色带；256 会有可见色阶 |
| `--passes` | 0 | **不做邻接合并**，小碎片全部保留（0 最保真） |
| `--epsilon` | 0.25 / 0.08 | 见上表 |
| `--min-area` | 1 | 只丢弃 1px 以下的碎片 |
| `--background` | 原图高频色 | **默认 `#000006` 是给暗图用的**，明亮图必须显式给 |
| `--dark-cut` | 暗图 14，亮图 0 | 把与底色相近的像素压平 |
| `--order` | `sketch` | 只影响回放观感，不影响 SVG 画面 |
| `--base` | `60 ÷ 笔数` | 1× 播放时长，忘了给会变成几十分钟 |

**取底色**（不依赖额外工具）：

```bash
python3 -c "
from PIL import Image; import numpy as np
a=np.array(Image.open('photo.jpg').convert('RGB')).reshape(-1,3)//8*8
c,n=np.unique(a,axis=0,return_counts=True)
print('#%02x%02x%02x'%tuple(c[n.argmax()]))"
```

### ② 补描边（消白点）

对 SVG 做：所有 `<path>` 补 `stroke="{同fill}"`，并插入
`<style>path{stroke-width:0.6;stroke-linejoin:round;stroke-linecap:round}</style>`。

`make_art.py` 已自动做，手改时别忘了——否则深色区域会有白点。

### ③ 出 Canvas 回放页

```bash
$PY tools/svg2canvas.py <in.svg> <原图> <out.html> "标题" <秒数> <线稿笔占比(0=自动)> <线稿时间占比> [线宽]
```

### ④ 校验保真度

```bash
$PY tools/verify_svg.py <in.svg> <原图> --out-prefix /tmp/verify
```

会输出 MAE 和三联对比图。参数必须与生成时一致，否则比的是另一份结果。

## 不同图类型的经验值

| 图类型 | 关键设置 | 实测结果 |
|---|---|---|
| 明亮繁杂照片 | `--background` 给高频色、`--dark-cut 0` | 海边人像 SSIM 0.9434 |
| 结构"硬"的图（建筑/直线多） | epsilon 给 0.08 | 走廊人像 SSIM 0.9154 |
| 暗背景照片 | `--background` 给背景色、`--dark-cut 14` | 夜景人像 MAE 0.386 |
| 扁平图标/logo | `--colors 192` 就够 | AceRacer 图标 MAE 2.676 |

---

## 保真度天花板

照片纹理矢量化之后**必然变成色块**，SSIM 大约卡在 **0.92~0.94**，
结构越"硬"、线条越多的图越低。想更接近照片只能堆笔数/分辨率，
换不来「照片感」——真要照片感得走保留位图纹理的另一条路。

判断"糊不糊"要用**原生分辨率**比对；缩到 720 宽看差异会明显变小。
