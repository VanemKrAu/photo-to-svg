# 原理与流程

## 整条流水线

```
原图 (jpg/png)
  │
  ├─[1] 颜色量化 ────────► 512 色，保留色带层次
  │
  ├─[2] 连通域切分 ──────► 每种颜色的每个连通块 = 一个"笔"
  │                        （不做邻接合并，小碎片全留）
  ├─[3] 轮廓提取 ────────► cv2.findContours + approxPolyDP(epsilon)
  │                        外轮廓 + 孔洞，用 evenodd 规则挖洞
  ├─[4] 局部渐变拟合 ────► 面积 ≥24px 的形状内部拟合线性渐变
  │                        （对区域内像素做最小二乘平面拟合 → SVD 取主方向）
  │
  ├─[5] 排序 ────────────► sketch：细长碎片优先 → 其余按面积降序
  │
  ├─[6] 输出 SVG ────────► <path fill=… fill-rule="evenodd" d=…>
  │                        + 补同色 stroke（消白点）
  │
  └─[7] 输出 Canvas 回放页
        ├─ 真线稿层 ────── Canny 边缘 → 折线追踪 → stroke 绘制
        ├─ 大色块切分 ──── 扫描线切成横条，像大笔刷一横条一横条刷
        ├─ 时间权重 ────── 0.15 + bbox面积×0.002，二分查找做时间↔笔号映射
        └─ 二进制打包 ──── TypedArray 零拷贝，DOM 里只有 1 个 canvas
```

## 关键设计

### 数据打包格式（`svg2canvas.py`）

```
header   'HX02' + N + NV + NR + NG        (20 字节)
verts    Int16 × NV × 2                    坐标 ×10（0.1px 精度）
offs     Uint32 × (N+1)                    每笔的顶点起点
cols     Uint32 × N                        颜色，高位是类型标记：
                                             0x01xxxxxx = 渐变填充
                                             0x02xxxxxx = 线稿描边（stroke，不 fill）
                                             其余       = 纯色填充
nring    Uint32 × (N+1)                    每笔的环起点
roffs    Uint32 × NR                       每个环的顶点起点
gpos     Float32 × NG × 4                  渐变的 x1,y1,x2,y2
gcol     Uint32 × NG × 2                   渐变的起止色
areas    Uint32 × N                        每笔的 bbox 面积（时间权重用）
```

整个 blob 做 base64 内嵌在 `<script type="text/plain">` 里，
JS 端用 TypedArray 视图**零拷贝**读取，一上来就 `new Float64Array(N)` 建权重表。

### 真线稿层（`build_lineart()`）

```
原图
 ├─ 双向双边滤波 ×2        压掉沙滩颗粒/皮肤噪点，保住结构边缘
 ├─ Canny(60, 150)         得到 1px 边缘
 ├─ 折线追踪               边缘像素放进 set，按 8 邻域走链；
 │                         优先从「度=1 的端点」起步（一条线尽量完整），
 │                         剩下的闭环再任意起头，短于 8 点的丢弃
 ├─ approxPolyDP(1.0)      简化
 ├─ 按 16 点切段           一条长线拆成若干"笔"，一笔一笔勾出来
 └─ 颜色 = 原图色 × 0.78   起稿阶段看得见，之后被色块完全盖住
```

**要点**：绝不能拿 `findContours` 的外轮廓去 `fill`——边缘密集处膨胀后会连成
大块，一填充就是一坨几何色块（见踩坑 #5）。**必须走描边。**

天空、云这类没有结构的区域 Canny 不产生边缘，所以**一笔都不落**——
这就是「只在有东西的地方起稿」的效果。

### 时间分配

```
每笔：weight = 0.15 + bbox面积 × 0.002            （大笔慢铺，碎片快过）
      —— 线稿层默认走同一条规则，不单独占时间

（可选）指定「线稿时间占比 T > 0」时，线稿反解成固定占比：
        L = T × Σ(色块权重) / ((1−T) × 线稿笔数)

累计权重表 CUM[i] = Σ weight[0..i-1]
时间 → 笔号：二分查找（strokeAtTime）
笔号 → 时间：CUM[n] / CUM[N]（timeOfStroke）
```

线稿按视觉重量自然播时，实测占整段时间约 3~7%（线稿笔数占比只有约 1%）；
固定占比（如 15%）会把起稿阶段拖到十几秒，2026-09-12 起不再默认使用。

### 大色块扫描线切分

**整幅画面 75% 的面积在前 1.94% 的笔里铺完**——线稿一结束就"啪"地糊一片。
对策：bbox 面积 > 7000 的色块，`cv2.fillPoly` 光栅化后按横条切开：

```python
step = max(8, min(h, int(round(9000 / w))))     # 每条目标 bbox 面积 ≈9000px²
for yy in range(0, h, step):
    band = mask[yy : yy+step+1]                 # ← +1：相邻条重叠一行，防白线
    for c in findContours(band, RETR_EXTERNAL): ...
```

切分条的渐变色按其**在渐变轴上的投影**取值，所以大渐变块拆完仍是连续渐变。

### 播放器

- **画布尺寸由 JS 精确计算**：`min(单元格宽 / W, 可用高 / H)`，
  配 `ResizeObserver` 实时重算。**不要用 `height:100% + aspect-ratio`**
  ——窄窗口下 `max-width` 生效时高度不跟着缩，比例会失真。
- **宽屏并排**：窗口 ≥1000px 且宽高比 ≥1 时双栏（左绘制 / 右原图）。
  原图 base64 只存一份，用 CSS 变量 `--ghostimg` 同时喂给两处。
- **PC 适配**：`@media (hover:hover) and (pointer:fine)` 给 hover 反馈；
  键盘 空格 / ←→ / Home / End / F；双击全屏；900px 与 1440px 两档断点。
- **离散回放**：每帧 `display`/`fill` 直接跳变，**不做任何补间动画**
  ——这样才像绘画录像回放。

## 工具分工

| 脚本 | 作用 |
|---|---|
| `tools/make_art.py` | **入口**。串起全流程 + 尺寸自检 |
| `tools/build_svg_art.py` | 描摹核心：量化 → 连通域 → 轮廓 → 渐变 → SVG |
| `tools/svg2canvas.py` | SVG → Canvas 回放页（线稿层、切分、时间轴、播放器） |
| `tools/verify_svg.py` | 栅格化重绘算 MAE，出三联对比图 |
| `tools/secret_scan.py` | 推送前的密钥自检 |
